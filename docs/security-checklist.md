# Security checklist

Состояние на **2026-09-27**, lab VM `sar-lab-1` (GCP, gVisor). Каждый пункт помечен
тем, **как** он проверен: `test` = автотест в `selftest.sh`, `manual` = проверено руками
на VM, `—` = не проверено / не сделано.

Модель угроз: агент внутри комнаты считается враждебным (любой shell, любой промпт).
Вызывающий API — один доверенный оператор (V0).

## Приоритет исправлений

1. **1.12 квота диска /workspace** — единственное, чем враждебный агент реально кладёт хост.
2. **3.3 LLM-прокси** — убирает ключ провайдера из комнаты; заодно точная классификация `MODEL_*` по HTTP-статусам.
3. **4.7 SSH/RDP firewall** — 5 минут работы.
4. **4.5 SSRF-фильтр** вебхуков — перед первым внешним пользователем.
5. Автотест на 2.5 (две комнаты одновременно) и 2.7 (reboot).
