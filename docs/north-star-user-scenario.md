# North Star user scenario

*Записано со слов пользователя, 2026-09-28. Это главный сценарий, под который
сверяются все остальные планы.*

## История

Я ставлю этот сервис себе на виртуальную машину и запускаю через него агентов
для всех своих задач: 3 агента тут, 5 агентов там, пачками, по API. У каждого
агента своё изолированное пространство, в чужое он залезть не может. Этим
закрывается огромная проблема безопасности и изоляции агентов. Мне не нужно
держать открытые терминалы и большой сторож на машине: я отправляю задачу, и она
делается, как Cloudflare Worker.

Мне всё равно, какой внутри агент (opencode, Claude Code, свой). Мне нужен
**просто агент**, который хорошо умеет GitHub, хорошо умеет браузер (Playwright)
и хорошо умеет Google-документы, и которому при запуске можно включить или
выключить нужные возможности.

## Критерий «дошли»

Пользователь переносит на этот сервис свою ежедневную работу с агентами. Все
агентные задачи, которые сегодня идут через терминалы и Session Manager на
ноутбуке, запускаются через API на машине. Ни одна не держит креды в комнате,
каждая заканчивается PR, файлом или явной ошибкой.

## Как проверяем, что движемся

- Трек universe-timeline: доля тиков, которые закончились смёрженным PR.
- Dogfood: доля `SILENT_FAILURE` и `NO_CHANGES` стремится к 0.
- Сколько собственных задач пользователя перенесено на API.
